# Shootareas

Annuaire MVP de lieux pour préparer des shootings photo, vidéo et contenus créatifs.

## Stack

- TanStack Start
- React
- Clerk
- Drizzle
- Turso/libSQL
- Tailwind CSS
- shadcn/ui-inspired components
- Bun

## Development

```bash
bun install
bun run db:push
bun run db:seed
bun run dev
```

## Environment

Copy `.env.example` to `.env` and fill the Clerk keys when testing protected routes.
